## Localization at the number level

Number formatting is one of those details that immediately reveals whether a product was designed for a language or merely translated into it. Nepali uses its own numeral glyphs and a lakh/crore grouping system, and both need to be handled explicitly.

This package converts numeric values into Nepali numerals and into Nepali words, including very large numbers. It is intentionally dependency-free so it can be used in a browser, a Node.js script, or an educational tool without adding weight.

## Small utility, high leverage

The package is now used as a reusable local utility for finance and localization work. The most valuable part is the testable boundary: one clear conversion API instead of ad-hoc formatting scattered across an application.

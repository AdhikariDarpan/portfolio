## Voice as a personal model

DRP Voice Studio is an in-progress platform for training a voice model on a speaker's own audio and using it to generate speech. The technical problem spans data preparation, model training, audio quality, and inference, but the product problem is equally important: voice data is personal, and the system should make ownership and consent explicit.

The pipeline uses FFmpeg, librosa, and torchaudio to normalize and segment source recordings before training. A Flask-based backend coordinates jobs, while the interface keeps the workflow understandable for someone who is not an audio engineer.

## Still being built

The project is not presented as a finished product. The training and generation pipeline is the current focus, followed by quality controls and a reviewable output workflow. The private case study documents the intended system and the decisions being made along the way.

## Password generation, without a black box

This package generates passwords and PINs from configurable character sets. It supports several strength presets and a multilingual set of characters, which is useful for localization testing as well as for applications that intentionally accept non-Latin input.

The implementation is dependency-free and exposes a small API. The important properties are predictable random selection, clear configuration, and no hidden network calls.

## Why multilingual

Most password generators assume Latin characters. Adding other scripts creates a useful test case for applications that claim to support international input, and it makes the generator flexible for different product requirements.

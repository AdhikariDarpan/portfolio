## Ask the image, not just OCR it

Extracting text is only part of understanding an image. This project combines OCR with a vision model and a text model so a user can ask a question about a screenshot, document, chart, or photo and get an answer grounded in both the text and the visual context.

The workflow preprocesses the image, extracts text with PaddleOCR, runs a vision-model pass, and then uses a local language model to reason over the combined output. Everything runs through Ollama, so the pipeline can operate without sending images to an external service.

## Local multimodal systems

The challenge is orchestration: passing the right context between OCR, vision, and reasoning without losing the source. The output is structured so the user can see the extracted text, a summary, and the model's answer separately.

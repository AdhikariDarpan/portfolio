## A visual layer over the browser

drpStudio explores a simple idea: let people arrange interface blocks visually, then give them code they can actually edit. The canvas is the workspace, not the final format.

Blocks can be moved, resized, aligned to a grid, and exported as a structured project. Importing an existing layout back into the editor keeps the tool useful beyond the first export.

## The exit path matters

Many visual builders are easy to enter and difficult to leave. This project treats export as a first-class feature: the result should be readable HTML, CSS, and JavaScript that another developer can take over.

The implementation is intentionally browser-native, using the Canvas API and plain JavaScript rather than a large application framework.

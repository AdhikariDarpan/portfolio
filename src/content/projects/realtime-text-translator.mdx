## Translation as a pipeline

This project uses transformer models for multilingual text translation, with mBART-50 as the primary many-to-many model and optional text-to-text pipelines for comparison. The focus was on a clean Python interface that could be reused across applications.

Bidirectional translation is handled through language tokens and model configuration rather than a separate model per language pair. That keeps the system compact and makes it easier to experiment with new directions.

## Practical constraints

Large translation models need memory and time. The implementation supports batch processing and exposes the model choice rather than pretending latency does not exist. It is a useful foundation for localization tooling and chat translation, not a claim of perfect translation quality.

## An ERP built from the API outward

Sajilo Invoice is a web-based invoice and ERP system for businesses that need more than a single invoice form. Company records sit at the top, with branches, warehouses, users, products, stock, suppliers, purchases, sales, and payments arranged around them.

The backend is a Go service built with Gin and a deliberate handler, service, repository split. Business rules stay out of HTTP handlers, SQL stays in repositories, and request and response types stay separate from database models. That structure made it practical to add modules without turning the API into a collection of unrelated endpoints.

## Typed frontend, shared contract

The frontend is a React and TypeScript admin workspace generated against the backend's Swagger contract. A sync script converts the Swagger snapshot to OpenAPI 3 and regenerates API types, so contract changes appear as reviewable diffs instead of drifting silently.

TanStack Query owns server state, Zustand holds the small amount of global session and UI state, and React Hook Form with Zod handles typed validation. An Axios interceptor keeps the token flow in one place: concurrent `401` responses share a single refresh request, retry the original calls, and clear the session if the refresh fails. Permission gates hide unavailable actions, while the API remains the authority.

## Delivery and operations

Database migrations are embedded into the Go binary and applied at startup, followed by idempotent seeders for roles, permissions, settings, and the first admin account. Docker Compose provides a repeatable local stack, while the production image is a multi-stage, non-root build.

GitHub Actions handles checks and image delivery, Swagger documents the API, and Railway hosts the deployed backend. Backup and migration scripts cover the operational work that a demo usually leaves out.

Both the API and frontend repositories are private, so this case study documents the architecture and product scope rather than exposing client data or deployment credentials.

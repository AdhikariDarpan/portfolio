## Organization without an account

Task Organizer is a local-first productivity tool: no sign-up, no sync service, no server dependency. The browser is the database, and export is the escape hatch.

The interface is built around spaces and groups. Tasks can be moved between lists with drag and drop, edited inline, and restored from a previous export. That balance of immediacy and durability is the core design goal.

## The cost of local-first

Local-first products have to be honest about data ownership. If the browser storage is cleared, the data is gone unless the user exported it. The tool makes backup a visible part of the workflow rather than hiding it behind an account.

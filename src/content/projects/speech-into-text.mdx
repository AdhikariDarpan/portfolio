## A small primitive, packaged well

Speech Into Text is a deliberately small package. It wraps browser speech recognition in a predictable API so a developer can add voice input to a note field or form without building the event handling from scratch.

The package supports language selection, continuous listening, and explicit start/stop control. It works with the browser's Web Speech API, which keeps the install light and the integration direct.

## Know the boundary

Browser speech recognition depends on the browser and its underlying service. The package is useful precisely because it does not pretend otherwise: it exposes the controls and events developers need to handle that reality.

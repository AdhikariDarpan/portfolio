## Local models for everyday code

This project explores a practical local alternative to cloud coding assistants. It wraps Ollama in a small Node.js package that can answer coding questions, help debug an error, or reason through an implementation without sending code to a third-party API.

The package is intentionally thin. It does not try to hide the model: users choose a local model, provide context, and get a response. That makes the trade-off between quality, speed, and privacy explicit.

## A useful constraint

Running locally means accepting hardware limits. The project is designed around that reality: small prompts, configurable models, and a workflow that works well for focused questions rather than giant repository-wide transformations.

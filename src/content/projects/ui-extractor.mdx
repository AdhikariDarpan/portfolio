## Turning pixels into structure

UI Extractor explores a difficult version of screenshot-to-code: not just identifying text, but recovering enough layout structure to generate something a developer can edit. The pipeline combines OCR with image analysis and element detection, then maps the result into several output formats.

The output targets reflect different workflows: Flutter for mobile prototypes, React and HTML/CSS for web, Tailwind for utility-first styling, and Markdown or Figma-oriented structures for design handoff. Each target has different assumptions, which forced the intermediate representation to stay relatively abstract.

## Honest limits

Screenshot-to-code is often presented as a one-click solution. In practice, the generated result is a scaffold: spacing, semantic structure, and component boundaries still need human judgment. This project was built with that limitation in mind, focusing on useful structure and editable output rather than claiming perfect reconstruction.

The code is private, but the case study captures the approach: detect what can be detected, preserve uncertainty where it exists, and make the generated artifact easy to correct.

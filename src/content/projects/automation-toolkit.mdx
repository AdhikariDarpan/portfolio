## Automation should be inspectable

This toolkit is a collection of Python utilities for work that is repetitive but not identical every time: browser interactions, system checks, file operations, and scheduled tasks.

Playwright handles browser automation, while psutil provides visibility into processes and resource usage. The scripts are intentionally small and composable; each one can be run independently or called from a larger workflow.

## Keep the operator in control

Automation gets dangerous when it hides what it is doing. The toolkit favors explicit steps, logged actions, and clear failure states so a person can understand and correct a run when the environment changes.

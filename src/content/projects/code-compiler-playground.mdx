## A fast place to test an idea

The playground is designed for the gap between “I have a snippet” and “I have a project.” Paste code, run it immediately, make a change, and export the result without setting up a local environment.

The editor and preview share a split-pane layout that adapts to smaller screens. Local persistence keeps work from disappearing when the tab closes, and ZIP export turns a browser experiment into files that can be moved into a real project.

## Small tool, real constraints

Running arbitrary HTML, CSS, and JavaScript in the browser requires attention to isolation, storage, and state. The PWA layer adds another concern: making the shell available offline without pretending that every feature can work without a browser environment.

The product is live and intentionally lightweight.

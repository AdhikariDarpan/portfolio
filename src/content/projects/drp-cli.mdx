## Make the boring parts repeatable

DRP CLI is a Go toolkit for starting and maintaining backend projects. Instead of a magical framework, it focuses on repeatable chores: scaffold a project, generate a migration, run the app with reload, produce API documentation, and package the result for deployment.

The tool is designed to leave a project that a developer can still understand. Generated code is visible and conventional; the CLI removes setup friction without taking ownership away from the application.

## Tested like a real tool

A CLI is easy to demo and harder to trust. The project includes a 37-test suite that runs in CI, along with Docker packaging and deployment paths for Render and Koyeb. That work turned it from a collection of scripts into something that can be installed and used with reasonable confidence.

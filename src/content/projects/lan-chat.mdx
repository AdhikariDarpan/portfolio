## Communication without the cloud

LAN Chat is built for environments where devices share a local network but should not depend on an external messaging service. It uses Electron for the desktop shell, Socket.io for local discovery and signaling, and WebRTC for direct peer-to-peer media and file transfer.

The product includes the unglamorous features that make a chat app usable: presence, notifications, friends, profiles, group conversations, and a file transfer flow that reports progress.

## Local-first networking is its own problem

Without a central server, discovery, connection state, and recovery become application concerns. The app has to handle devices joining and leaving, peers that cannot connect directly, and the difference between a message that was sent and one that was actually delivered.

The public repository captures the approach and the trade-offs of building a useful local communication tool.
